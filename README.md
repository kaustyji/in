# Kaustubh Patel – Safety Officer Portfolio (Vite, single page)
- `npm install`, then `npm run dev` (or `npm run build`)
- Everything is in `index.html` (content), `src/style.css` (design) and `src/main.js` (menu, sliders, contact form). No React.
- Photos: replace the files in `public/images/` (see IMAGE-REPLACEMENT-GUIDE.md). Resume: `public/assets/resume.pdf`.
- Contact form opens the visitor's email app (mailto); no server or secrets.
